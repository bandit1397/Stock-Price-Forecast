# 한국·미국 주식 종합 분석과 알림

41개 종목과 15개 산업을 매일 분석해 매수 후보, 대기, 매도 검토, 회피 판단을 텔레그램으로 보내는 무료 시스템입니다. 일일 보고에는 원자재 시세, 광물·방산 종목, 평소와 다른 움직임(특이 사항)도 들어갑니다. 자동 주문은 하지 않습니다.

> 투자 판단 참고용입니다. 수익을 보장하지 않으며 손실의 책임은 투자자에게 있습니다.

## 이 프로그램이 할 수 있는 것과 없는 것

주가의 방향과 정확한 매매 시점을 맞히는 프로그램은 만들 수 없습니다. 실제로 검증해 보면 그렇습니다. 그래서 이 프로그램은 아래처럼 동작합니다.

| 구분 | 내용 |
|---|---|
| 하는 일 | 좋은 회사를 가격과 분리해 평가, 위험 신호 차단, 기간별 가격 범위 제시, 손절선과 비중 계산 |
| 하지 않는 일 | 검증되지 않은 상승 확률 표시, 자동 주문, 주가조작 판정 |

### 검증 결과 (2026-11-05, 대시보드 `검증 결과` 탭에서 최신값 확인)

- **상승 예측 모델**: 12개 검증(6개 기간 × 2개 대상) 중 0개 통과. 머신러닝 모델이 "항상 오른다"는 단순 기준보다 낫다는 증거가 없어 확률을 표시하지 않습니다. 통과하는 기간이 생기면 자동으로 표시됩니다.
- **80% 가격 범위**: 1일~1개월 82~83%, 6개월 81%, 1년 78%, 2~3년 75% 포함. 긴 기간은 다소 좁습니다.
- **시점 규칙 백테스트 (2012년~, 비용 포함)**: 연수익 16.7%로 단순 보유 29.9%보다 낮고, 최대낙폭은 -17.7%로 보유 -35.2%의 절반입니다. 수익을 늘리는 규칙이 아니라 손실을 줄이는 규칙입니다.
- **검증하지 못한 것**: 기술·재무·뉴스 점수와 기간별 가중치는 과거 시점의 값이 없어 검증하지 못했습니다. 백테스트 종목은 현재 시점에 고른 것이라 절대 수익률은 부풀려져 있습니다.

## 판단 방식

1. **위험 차단**: 이상거래 위험 70점 이상이나 중대 공시가 있으면 회피
2. **좋은 회사 관문**: 기술력 → 시장 수요 → 수익성
3. **좋은 가격 관문**: 역DCF로 주가에 반영된 성장률과 실제 성장 능력을 비교
4. **시점**: 추세, 과열, 시장 환경, 3일 내 실적 발표, 급락 여부

네 관문과 시점을 모두 통과해야 `매수 후보`입니다. 회사는 좋은데 시점이나 가격이 맞지 않으면 `매수 대기`, 차트와 기업 평가가 모두 나쁘면 `매도 검토`입니다.

기술 점수 100점 중 80점은 `config/tech_moat.yaml`의 평가표에서 나옵니다. 초기값은 Claude의 의견이므로 직접 고쳐서 쓰세요. 나머지 20점은 재무 데이터로 자동 계산합니다. 근거가 부족한 종목(`c: low`)은 기술 관문을 통과할 수 없습니다.

| 분석 영역 | 데이터 | 비용 |
|---|---|---|
| 시세, 재무, 원자재, 환율, 지수 | Yahoo Finance (yfinance, 개인 연구용, 장중 지연 가능) | 무료 |
| 금리, 물가, 고용, 신용 스프레드 | FRED | 무료 |
| 뉴스, 정치·사회 이슈 12종 | Google News RSS (제목 키워드 방식) | 무료 |
| 외국인·기관 수급 | 네이버 금융 (비공식 경로, 실패해도 계속 실행) | 무료 |
| 미국 공시 | SEC EDGAR (`SEC_CONTACT` 필요) | 무료 |
| 한국 공시 | OpenDART (`DART_API_KEY` 필요) | 무료 |

## 설치 (Windows)

1. [Python](https://www.python.org/downloads/)을 설치합니다. `Add python.exe to PATH`를 체크하세요.
2. `setup.bat`을 실행합니다.
3. `run_daily.bat`을 실행합니다. 첫 실행은 3~5분 걸립니다.
4. `dashboard.bat`을 실행하면 브라우저에 분석 화면이 열립니다.

> Chrome 자동 번역이 켜져 있으면 한국어 문구가 왜곡될 수 있습니다(예: `매수 후보`가 다른 말로 표시). 주소창의 번역 아이콘에서 이 페이지의 번역을 끄세요.

## 갤럭시 알림 연결 (텔레그램)

**쉬운 방법**: BotFather에서 봇을 만들고 `connect_phone.bat`을 실행해 토큰을 붙여 넣으세요. 채팅 ID 확인, `.env` 저장, 시험 메시지, GitHub 등록을 자동으로 처리합니다. USB 연결은 필요 없습니다.

**직접 설정하는 방법**:

1. 텔레그램에서 `@BotFather`를 열고 `/newbot`으로 봇을 만들어 토큰을 받습니다.
2. 만든 봇에게 아무 메시지나 보냅니다.
3. 브라우저에서 `https://api.telegram.org/bot<토큰>/getUpdates`를 열어 `"chat":{"id":숫자}`의 숫자를 확인합니다.
4. `.env` 파일에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`를 넣습니다.
5. `.venv\Scripts\python -m stockai test-telegram`으로 확인합니다.

토큰은 비밀번호입니다. 이 저장소는 공개되어 있으니 코드에 쓰지 말고 `.env`나 GitHub Secrets에만 넣으세요.

## 자동 실행 (둘 중 하나만)

**GitHub Actions (권장, PC가 꺼져 있어도 동작)**: 저장소 `Settings > Secrets and variables > Actions`에 `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, 필요하면 `DART_API_KEY`, `SEC_CONTACT`를 등록합니다. 평일 양국 장 마감 후 일일 보고, 장중 매시간 급변 점검이 실행됩니다. 실행 시각은 수십 분 늦어질 수 있습니다.

**Windows 작업 스케줄러**: `setup_schedule.bat`을 실행합니다. PC가 켜져 있어야 합니다.

## 종목 변경과 보유 종목

- 종목 추가: `config/universe.yaml`과 `config/tech_moat.yaml`에 함께 추가합니다.
- 보유 종목 점검: `config/portfolio.example.yaml`을 `portfolio.yaml`로 복사해 수정합니다.
- 기준 변경: `config/settings.yaml`

## 명령

```
python -m stockai run            시세 갱신, 분석, 보고, 알림
python -m stockai scan           장중 급변과 손절선 점검
python -m stockai train          예측 모델 재검증 (run이 7일마다 자동 실행)
python -m stockai backtest       시점 규칙 백테스트
python -m stockai test-telegram  알림 연결 확인
python -m pytest tests           테스트
```

## 알려진 한계

- 뉴스는 제목 키워드만 봅니다. 문맥을 이해하지 못해 오탐이 있습니다. 그래서 뉴스만으로는 회피 판단을 내리지 않습니다.
- 경기순환주는 고점 이익 때문에 싸 보일 수 있어 평균 이익률로 보정하지만 완벽하지 않습니다.
- 한국 종목의 재무 데이터는 Yahoo 기준이라 누락이 있습니다.
- 투자경고·공매도 과열 같은 거래소 지정 정보는 아직 반영하지 않았습니다.
- 세금과 비용은 `config/settings.yaml`의 가정값이므로 본인 증권사 기준으로 확인하세요.
